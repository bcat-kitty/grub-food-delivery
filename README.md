# Grub - UberEats Clone

Grub is a full-featured UberEats clone app template written in Java/Kotlin for Android, iOS, Desktop, and Web. Built with Codename One and the CodeRAD library, it demonstrates how to create a cross-platform food delivery app with reusable UI components and a cleanly separated MVC structure.

The app is UI-focused and not wired to a backend — all logic is for visual effect — but it's structured to make connecting a server straightforward.
